# Agent-Based AI

## What is Agent-Based AI?

Agent-based AI means **you give the AI a goal**, and the AI decides what steps and tools it needs.

Simple example:

```text
You:
"Find 10 SEO keywords,
analyze competitors,
write an article,
and create a report."

        ↓

AI Agent
        ↓
Chooses tools
        ↓
Researches
        ↓
Analyzes
        ↓
Creates the result
```

You normally do not define every step manually.

The agent can decide:
- what to do first
- which tool to use
- when to search
- when to write code
- when to open a website
- when to create a file

## Main Advantages

- more autonomous
- good for complex tasks
- can make decisions
- can use different tools
- useful when the exact steps are not known
- good for research
- good for changing tasks

---

## Agent vs Workflow

```text
Workflow-Based:

You decide:
Step 1
Step 2
Step 3
Step 4


Agent-Based:

You give:
"Complete this goal"

AI decides:
Step 1
Step 2
Step 3
...
```

---

## Important

Agent-based does not mean the AI can do absolutely anything.

The agent still needs:
- permission
- connected tools
- APIs
- browser access
- file access
- other integrations

---

## Simple Summary

```text
Workflow-Based = You decide the steps

Agent-Based = AI decides the steps

LLM = Brain

Tools/APIs = Hands
```

Use agent-based AI when the task is complex and the AI needs to decide what to do next.
